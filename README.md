# Credit Card Application Processing & SLA Performance Dashboard

## 📌 Project Overview
This project analyzes credit card application processing data to understand application status, processing time, SLA performance, and business trends using Google Sheets.

## 🔗 Live Google Sheets Dashboard
- [View Interactive Google Sheets Dashboard](https://docs.google.com/spreadsheets/d/1cL7NnBkaahg0_oIaRLI62QC-p5PvOCSPm-3pmrQM9Jk/edit?usp=sharing)

## 🎯 Project Objectives
- Analyze credit card application performance.
- Track approval and rejection rates.
- Monitor SLA breaches and pending overdue applications.
- Analyze processing time (TAT).
- Identify trends across cities, card types, and application channels.

## 🛠️ Tools & Skills Used
- Google Sheets
- Data Cleaning
- Spreadsheet Formulas
- Pivot Tables
- KPI Analysis
- Data Visualization

## 📊 Key Project Metrics
- **Total Applications:** 750
- **Approved Applications:** 486
- **Rejected Applications:** 165
- **Under Review:** 99
- **SLA Breached:** 240
- **Pending Overdue:** 97
- **Approval Rate:** 64.8%

## 🔍 Key Insights
- **Bangalore** recorded the highest applications (**170**).
- **August** recorded the highest monthly applications (**82**).
- **RM Referral** was the fastest processing channel, with an average TAT of **4.51 days**.
- **97** pending applications were overdue.
